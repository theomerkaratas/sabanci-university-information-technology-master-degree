SEC 509 — Secure Coding & Software Security

This folder contains the materials and notes for SEC 509: Secure Coding & Software Security, a core course in the Master of Science in Information Technology program at Sabancı University. You can also learn more about the program here: https://fens.sabanciuniv.edu/en/msit

📘 Course Overview

SEC 509 explores the ubiquity of software, impact of software failure, threat modeling concepts (STRIDE, D.R.E.A.D.), and foundational security practices.

📚 Course Chapters

Chapter 1

Explores the ubiquity of software, impact of software failure, threat modeling concepts (STRIDE, D.R.E.A.D.), and foundational security practices.

Chapter 2

Focuses on Pluggable Authentication Modules (PAM), configuring password complexity policies with pam_pwquality, and enforcing password history to prevent reuse.
