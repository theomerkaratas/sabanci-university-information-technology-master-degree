# SEC509 - Lab 1: Threat Modeling

This laboratory work contains a comprehensive threat modeling analysis for the **OrcunCorp Document Sharing Tool**.

## Contents

Key files created during the lab:

- **Reports:**
  - `omerkaratas_SEC509_Lab1_Threat_Modeling_Report.pdf`: Main report including detailed analysis and findings.
  - `omerkaratas_full-report.htm`: Technical report exported from the Microsoft Threat Modeling Tool.
- **Modeling Files:**
  - `omerkaratas_context-diagram.tm7`: System context diagram (Tool file).
  - `omerkaratas_final-diagram.tm7`: Final threat model diagram (Tool file).
- **Visualizations (`.png`):**
  - Data Flow Diagrams (DFD), trust boundaries, and specific design protections against threats like SQL Injection.

## Tools Used

- **Microsoft Threat Modeling Tool:** Used for creating diagrams and automatically generating threat lists based on the STRIDE methodology.
