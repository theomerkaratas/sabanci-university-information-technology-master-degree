IT 501 – PYTHON FUNDAMENTALS

Course Overview

This repository contains various Python projects developed and optimized as part of the IT501 course. All projects have undergone comprehensive debugging, have been made resilient to invalid user inputs, and are fully compatible with local development environments.

The IT501 Python Fundamentals course focuses on core Python concepts through practical, engaging projects. Students develop critical thinking and problem-solving skills while building real-world applications.

🐍 Python Topics Covered

Variables & Data Types

Strings, integers, floats, and complex data structures.

Control Flow

Conditionals (if/else) and loops (for/while).

Functions

Function definition, parameters, return values, and scope.

Lists & Collections

Lists, tuples, sets, and dictionary operations.

Error Handling

Try-except blocks and input validation.

Module Organization

Modular code structure and file organization.

🎮 Projects

♠️ Blackjack

A classic card game implementation following standard Blackjack rules with an intelligent scoring system.

  • • Card Deck Management: Proper deck shuffling and card distribution
  • • Scoring Logic: Hand evaluation with Ace flexibility (1 or 11)
  • • Player vs Dealer: Complete game flow with turn-based mechanics
  • • ASCII Art: Visual card representation and game status display

Key Concepts: Lists, Functions, Conditionals, Loops

🧮 Calculator

A robust arithmetic calculator with comprehensive invalid input protection and division-by-zero prevention.

  • • Basic Operations: Addition, subtraction, multiplication, division
  • • Error Handling: Division by zero, non-numeric inputs, invalid operations
  • • Input Validation: Type checking and operation verification
  • • User-friendly Interface: Clear prompts and result display

Key Concepts: Functions, Error Handling, Input Validation

🔐 Caesar Cipher

A security tool that encrypts and decrypts text using the classic alphabet shift method.

  • • Encryption/Decryption: Shift cipher with configurable offset
  • • Character Handling: Preserves spaces and special characters
  • • Case Sensitivity: Maintains uppercase/lowercase distinction
  • • Brute Force Capability: Optional all-shift decryption

Key Concepts: String Manipulation, ASCII Values, Loops

☕ Coffee Machine

A simulated vending machine application with sophisticated resource management and coin validation.

  • • Menu Selection: Multiple beverage options with pricing
  • • Resource Management: Track water, coffee, milk inventory
  • • Payment Processing: Coin validation and change calculation
  • • Maintenance Reports: Check resources and refill notifications

Key Concepts: Dictionaries, Conditionals, Math Operations, State Management

🎯 Hangman

The classic hangman game with an extensive word list and visual progression stages.

  • • Word Selection: Random word picking from comprehensive word list
  • • Game Mechanics: Letter guessing with attempt tracking
  • • Visual Feedback: ASCII art hangman progression stages
  • • Win/Loss Conditions: Proper game state detection and messaging

Key Concepts: Lists, Loops, String Operations, Game Logic

📊 Higher-Lower

A trivia game based on comparing follower counts of famous accounts with comprehensive score tracking.

  • • Celebrity Database: Extensive list of famous accounts and followers
  • • Comparison Logic: Higher/lower guessing with validation
  • • Score Calculation: Progressive scoring with streak multiplier
  • • Game State Management: Replay functionality and score preservation

Key Concepts: Dictionaries, Random Selection, Data Comparison, Conditionals

✨ General Features

🛡️ Error Handling

Invalid inputs (letters instead of numbers, etc.) do not crash the programs. Comprehensive try-except blocks and input validation ensure robust operation.

📦 Modular Structure

Data, ASCII art, and core logic are organized into separate files for clarity, maintainability, and code reusability.

💻 Local Compatibility

Platform-specific dependencies (like replit libraries) have been replaced to ensure functionality across all systems and development environments.

🎨 User Experience

Clear instructions, visual feedback, and intuitive interfaces make all projects accessible to users of all skill levels.

🚀 Getting Started

Prerequisites

  • • Python: Version 3.7 or higher
  • • Terminal/Command Prompt: For running scripts
  • • Text Editor or IDE: VS Code, PyCharm, or similar

Running a Project

Navigate to project directory and run:

cd [project-name]
python main.py
