# Practice 9: CSS Box Model Basics

This practice introduces the fundamental concept of the CSS Box Model through simple geometric shapes.

## Topics Covered

- **Dimensions:** Setting `height` and `width` in pixels.
- **Padding:** Space between the content and the border.
- **Border:** The line surrounding the padding and content.
- **Margin:** Space outside the border to separate elements.
- **Box Interaction:** Adjusting margins to make corners touch.

## Box Model Breakdown

| Layer       | Property         | Description                      |
| :---------- | :--------------- | :------------------------------- |
| **Content** | `width`/`height` | The actual content area.         |
| **Padding** | `padding`        | Inner spacing around content.    |
| **Border**  | `border`         | The frame around the element.    |
| **Margin**  | `margin`         | Outer spacing to other elements. |

## Multiple Borders Shortcut

- `border-width: 20px 10px;` sets 20px for top/bottom and 10px for left/right.
