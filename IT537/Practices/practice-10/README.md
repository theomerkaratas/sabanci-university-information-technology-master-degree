# Practice 10: Motivational Poster

A practical project applying the Box Model and accessibility for a centered poster layout.

## Topics Covered

- **Text Transformation:** Using `text-transform` for `uppercase` or `capitalize`.
- **Centering Techniques:** Achieving horizontal centers using `margin: 0 auto` or calculated percentages.
- **Borders on Images:** Adding frames to visuals using the `border` property.
- **Composition:** Wrapping elements in a container `div` for collective management.

## Text Styling Table

| Property         | Value        | Effect                                      |
| :--------------- | :----------- | :------------------------------------------ |
| `text-transform` | `uppercase`  | ALL CAPS TEXT.                              |
| `text-transform` | `capitalize` | Capitalizes The First Letter Of Each Word.  |
| `text-align`     | `center`     | Centers text horizontally in its container. |

## Layout Tip

To horizontally center a `div`, set a specific `width` (e.g., `50%`) and use `margin-left: 25%` or simply `margin: auto`.
