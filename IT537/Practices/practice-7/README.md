# Practice 7: Color Styling and Static Assets

This practice focuses on applying specific styles to elements using hierarchical selectors and managing static assets.

## Topics Covered

- **CSS for Specific IDs:** Using IDs to apply unique colors (e.g., `red`, `blue`).
- **Resetting Defaults:** Removing default browser styling like `font-weight: bold` from headings.
- **Image Sizing with CSS:** Controlling image dimensions (`width`, `height`) via CSS instead of HTML attributes.
- **External Asset Linking:** Organizing and linking images from subdirectories.

## CSS Styling vs. HTML Attributes

| Task            | Recommended Way (CSS)  | Description                      |
| :-------------- | :--------------------- | :------------------------------- |
| **Color**       | `color: red;`          | Setting text color.              |
| **Font Weight** | `font-weight: normal;` | Removing bold property.          |
| **Dimensions**  | `width: 200px;`        | Defining size in the stylesheet. |

## Files

- `index.html`: Structure of the color vocabulary page.
- `style.css`: All styling logic.
- `assets/images/`: Folder for color-coded images.
