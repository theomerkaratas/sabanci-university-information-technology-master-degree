# Practice 6: CSS Selectors

This practice explores different ways to target HTML elements for styling.

## Topics Covered

- **Element Selector:** Targets all instances of a specific tag (e.g., `p`).
- **Class Selector:** Targets elements with a specific class (e.g., `.note`).
- **ID Selector:** Targets a single unique element (e.g., `#id-selector-demo`).
- **Attribute Selector:** Targets elements based on attribute presence or value (e.g., `[value="4"]`).
- **Universal Selector:** Targets every element on the page (`*`).

## Selector Syntax

| Selector  | Example           | Target                                  |
| :-------- | :---------------- | :-------------------------------------- |
| Tag       | `p { ... }`       | All `<p>` elements.                     |
| Class     | `.note { ... }`   | All elements with `class="note"`.       |
| ID        | `#unique { ... }` | The element with `id="unique"`.         |
| Attribute | `[type="text"]`   | Elements with matching attribute/value. |
| Universal | `* { ... }`       | All elements.                           |
