IT511 — Fundamentals of Data Communication and TCP/IP Networks

This folder contains the materials, lab exercises, and notes for IT511: Fundamentals of Data Communication and TCP/IP Networks, a core course in the Master of Science in Information Technology program at Sabancı University. You can also learn more about the program here: https://fens.sabanciuniv.edu/en/msit

📘 Course Overview

IT511 focuses on the fundamentals of data communication and TCP/IP networks. It provides the essential knowledge to understand network architectures, protocols, and practical lab applications.

This directory contains Notes and Lab Exercises to help you dive deeper into networking concepts.
