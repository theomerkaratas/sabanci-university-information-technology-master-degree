IT 524 – OBJECT-ORIENTED PROGRAMMING WITH JAVA

Course Overview

This folder contains the coursework and projects completed for IT 524: Object-Oriented Programming with Java, a core course in the Master of Science in Information Technology program at Sabancı University. The course emphasizes practical development using Java and object-oriented design principles.

IT524 focuses on software development using Java and object-oriented programming (OOP). Topics include classes and objects, inheritance, polymorphism, exception handling, collections, file I/O, and design patterns. Projects demonstrate applied OOP concepts through real application development.

🎓 Core Topics

🏗️ Object-Oriented Fundamentals

Classes, objects, encapsulation, and information hiding principles.

🔄 Inheritance & Polymorphism

Class hierarchies, method overriding, and dynamic dispatch.

⚠️ Exception Handling

Try-catch blocks, custom exceptions, and error management.

📦 Collections Framework

Lists, Sets, Maps, and data structure implementations.

📁 File I/O & Streams

File operations, byte/character streams, and serialization.

🎨 Design Patterns

Creational, structural, and behavioral design patterns.

📂 Projects

🏦 BankAccountProject

A comprehensive banking application demonstrating core OOP principles through practical implementation of account management and financial operations.

  • • Account Management: Create and manage bank accounts with multiple types
  • • Transaction Processing: Deposit, withdrawal, and transfer operations
  • • Inheritance Hierarchy: Different account types with specialized behaviors
  • • Exception Handling: Comprehensive error handling for invalid operations
  • • Data Persistence: CSV-based account storage and retrieval
  • • User Interface: Command-line or GUI-based interaction

Key Concepts: Encapsulation, Inheritance, Polymorphism, Exception Handling, File I/O

⚽ FootJoy

A sports management system simulating football match coordination, demonstrating advanced OOP concepts through team and player management.

  • • Match Management: Organize and track football matches
  • • Player Hierarchy: Home and away players with different behaviors
  • • Ball Management: Ball state and possession tracking
  • • Custom Exceptions: Ball access controls and game rules
  • • Game Simulation: Real-time match simulation and scoring
  • • Statistics Tracking: Match statistics and player performance

Key Concepts: Polymorphism, Interface Implementation, Custom Exceptions, Collections

🚀 Getting Started

Prerequisites

  • • Java Development Kit (JDK): Version 11 or higher
  • • IDE: IntelliJ IDEA, Eclipse, or VS Code with Java extensions
  • • Maven or Gradle (optional): For build management

Running Projects

To compile and run Java programs:

javac *.java
java ClassName

For projects with build files:

mvn clean compile
mvn exec:java

💡 Key OOP Principles

Encapsulation

Bundle data and methods together, hiding internal implementation details from the outside world.

Inheritance

Create class hierarchies to promote code reuse and establish relationships between classes.

Polymorphism

Allow objects to take multiple forms and be treated uniformly through a common interface.

Abstraction

Define abstract concepts and contracts, reducing complexity by hiding unnecessary details.

Single Responsibility

Each class should have one reason to change, promoting maintainability and clarity.

DRY Principle

Don't Repeat Yourself - avoid code duplication through inheritance and composition.
