# IT 526: Kurumsal Java Çatıları ve Tasarım Kalıpları ☕🏛️

IT 526 dersi, ileri Java kullanımı, GoF tasarım kalıpları ve modern çatı mimarileriyle kurumsal yazılım tasarlama ve geliştirme zorluklarını ele alır.

> **Kaynak kodu ve dönem projesi:** Java dönem projesinin tam uygulaması ve kaynak paketleri [IT526 GitHub klasöründe](https://github.com/theomerkaratas/sabanci-university-information-technology-master-degree/tree/main/IT526) bulunur.

## Temel konular

- **Tasarım kalıpları:** Yaratımsal Factory; yapısal Decorator; davranışsal Strategy, Command ve Observer kalıplarının uygulanması.
- **Modern Java deyimleri:** JDK 16+ Record'ları, gelişmiş `switch` ifadeleri, lambda'lar ve Stream API.
- **Yazılım mimarisi ilkeleri:** Açık/Kapalı (OCP), Tek Sorumluluk (SRP) ve alan mantığıyla kullanıcı arayüzü katmanlarını temiz biçimde ayırma.
