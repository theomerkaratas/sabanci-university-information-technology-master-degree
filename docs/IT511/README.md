# IT 511: Fundamentals of Data Communication and TCP/IP Networks 🌐

Welcome to the **IT 511: Fundamentals of Data Communication and TCP/IP Networks** documentation section. This course explores the core architectural principles, protocol mechanisms, and operational foundations of modern computer networks and the Internet protocol suite.

## 📚 Curriculum & Knowledge Areas

The documentation for this course is organized into structured theoretical notes, visual diagrams, and examination review materials:

### [📓 Comprehensive Lecture Notes](./Notes/LectureNotes/README.md)
Detailed theoretical and architectural breakdowns complete with protocol diagrams:
* **Transport Layer Foundations:** Principles of Reliable Data Transfer (RDT 1.0, 2.0, 2.1, 2.2, 3.0), Pipelined Protocols (Go-Back-N, Selective Repeat).
* **TCP Deep-Dive:** TCP Segment Structure, Connection Management (2-way vs. 3-way handshakes), Flow Control, Congestion Control (TCP Tahoe, TCP Reno, TCP Cubic, AIMD).
* **Network Layer & Routing:** Data plane vs. Control plane, IPv4/IPv6 addressing, Subnetting & CIDR, Longest Prefix Match algorithms, SDN vs. Traditional per-router architectures.

### [❓ Exam Review & Q&A](./Notes/QuestionsAndAnswers/README.md)
Structured question-and-answer repository covering numerical problems, sequence number tracking, subnet calculation exercises, and protocol state transitions.
