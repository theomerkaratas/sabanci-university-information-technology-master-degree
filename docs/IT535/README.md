# IT 535 – Mobile Programming 📱

Welcome to the **IT 535: Mobile Programming** course directory!

This folder contains documentation, notes, coursework, and project links for the **IT 535: Mobile Programming** course completed as part of the **Sabancı University M.S. in Information Technology** program.

---

## 🎯 Course Overview

IT 535 focuses on modern cross-platform mobile application development using the **React Native** and **Expo** ecosystem. The course covers building scalable, production-grade mobile applications for iOS and Android with modern user authentication, styling systems, product analytics, file routing, and cloud build pipelines.

---

## 🚀 Main Project: Subscrio 💳

- **Repository**: [theomerkaratas/subscrio](https://github.com/theomerkaratas/subscrio)

**Subscrio** is a mobile application developed as the primary project for IT 535. It helps users manage and track their recurring subscriptions, upcoming renewals, and spending analytics.

---

## 🛠️ Technology Stack & Tools

- **Framework & Core**: [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
- **Navigation & File-Based Routing**: [Expo Router](https://docs.expo.dev/router/introduction/)
- **Authentication & User Management**: [Clerk](https://clerk.com/)
- **Product Analytics & Event Tracking**: [PostHog](https://posthog.com/)
- **Build & Cloud Deployment**: [EAS (Expo Application Services)](https://expo.dev/eas)
- **Styling**: [NativeWind](https://www.nativewind.dev/) (Tailwind CSS for React Native)
- **Language & Runtime**: TypeScript / Node.js

---

## 📚 Topics Covered

| Topic | Description | Key Technologies |
| ----- | ----------- | ---------------- |
| **Mobile Architecture & Navigation** | File-based routing, stack & tab navigation, modal flows | Expo Router, React Native |
| **User Authentication & Authorization** | OAuth, secure session storage, protected screens | Clerk |
| **UI Design & Utility-First Styling** | Responsive layouts, dark/light themes, Tailwind utility classes | NativeWind |
| **Analytics & Telemetry** | User behavioral tracking, feature flags, event capture | PostHog |
| **Build & Distribution Pipelines** | Cloud builds, OTA updates, production credentials & provisioning | EAS Build & Submit |
| **State Management & Async Data** | Local & global state management, async data fetching | React Hooks, Context API |
