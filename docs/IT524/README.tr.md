# IT 524: Java ile Nesne Yönelimli Programlama ☕

Sabancı Üniversitesi **Bilgi Teknolojileri Yüksek Lisans Programı** kapsamındaki bu temel ders; ileri Java geliştirme, yazılım tasarım ilkeleri, eşzamanlılık ve nesne yönelimli tasarım kalıplarını ele alır.

> **Kaynak kodları ve proje depoları:** Java kaynak kodu, derlenmiş dosyalar ve proje mimarileri [IT524 GitHub klasöründe](https://github.com/theomerkaratas/sabanci-university-information-technology-master-degree/tree/main/IT524) bulunur.

## Temel yeterlilikler

- **Nesne yönelimli tasarım (OOD):** Kapsülleme, kalıtım hiyerarşileri, soyut sözleşmeler ve çalışma zamanı çok biçimliliği.
- **Eşzamanlılık ve senkronizasyon:** Java eşzamanlılık araçlarıyla çok iş parçacıklı programlama (`ReentrantLock`, `Condition`, `volatile` ve paylaşılan durumun güvenli eşzamanlanması).
- **Savunmacı ve dayanıklı yazılım:** Özel istisnalar, güvenli durum doğrulama ve kaynakların doğru yönetimi.
- **Yazılım mimarisi:** SOLID ilkeleri, katmanlı mimari, UML modelleme ve tasarım ödünleşimleri.
